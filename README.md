## Setup

1. Install Node.js 18 or newer.
2. Copy `.env.example` to `.env`.
3. Fill in the required credentials locally; do not commit `.env`.
4. Install dependencies with `npm install`.
5. Start the bot with `npm start`.

The repository intentionally excludes local secrets, runtime session files, and generated output. Optional third-party API keys are read from environment variables when supported by the corresponding command.
